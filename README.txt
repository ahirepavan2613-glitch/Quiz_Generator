QUIZ GENERATOR
==============

Quiz Generator is a simple Python program that asks multiple-choice
questions and calculates the user's final score.

FEATURES
--------
- Multiple-choice questions
- Instant correct/wrong feedback
- Score calculation
- Percentage calculation
- Performance message

HOW TO RUN
----------
1. Install Python.
2. Open the project folder in VS Code or PyCharm.
3. Run:

    python quiz_generator.py

CONCEPTS USED
-------------
- Lists
- Dictionaries
- Loops
- If-else statements
- Functions
- User input
- Score calculation
